# نگار | Negar

## فارسی

**نگار** نرم‌افزاری قدیمی برای نمایش و مدیریت مجموعه‌های تصاویر و دسترسی به چند امکان جانبی روزانه است.

### امکانات نسخهٔ قدیمی

- **مجموعه‌های تصاویر:** نمایش مجموعه‌ها و مرور تصاویر به‌صورت بندانگشتی.
- **محافظ صفحه‌نمایش:** استفاده از تصاویر در محافظ صفحه‌نمایش نگار.
- **تاریخ:** دسترسی به بخش تاریخ برنامه.
- **یادداشت‌ها:** دسترسی به بخش یادداشت‌ها.
- **اذان:** دسترسی به بخش مربوط به اذان.
- **تنظیمات:** مدیریت تنظیمات برنامه.
- **دربارهٔ نگار:** مشاهدهٔ اطلاعات برنامه.

این مخزن برای نگهداری و انتشار نسخهٔ قدیمی نگار و فایل‌های مربوط به آن است.

---

## English

**Negar** is a legacy application for viewing and managing picture collections, with several additional daily-use features.

### Features of the legacy version

- **Picture collections:** Browse collections and view image thumbnails.
- **Screen saver:** Use pictures with the Negar screen saver.
- **Date:** Access the application's date section.
- **Notes:** Access the notes section.
- **Adhan:** Access the Adhan-related section.
- **Settings:** Manage application settings.
- **About Negar:** View information about the application.

This repository is intended to preserve and share the legacy Negar application and its related files.
